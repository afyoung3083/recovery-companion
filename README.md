# Recovery Companion

An AI-assisted Twelve-Step recovery companion that supplements—not replaces—human sponsors, fellowship, professional care, or a user's Higher Power.

## Sprint 1 goal

Build the first command-line recovery conversation:

1. Accept one user message.
2. Apply the Recovery Knowledge Specification core reasoning framework.
3. Return a compassionate, recovery-centered response.
4. Recommend three ranked next-right actions.

## Current status

Project skeleton initialized. No application code or API integration has been added yet.
